# 📄 q-aTool: AI Assistant for PDFs in Chrome

**q-aTool** is a Chrome extension that empowers users to interact with PDF documents directly within their browser. By leveraging AI capabilities, this tool allows users to ask questions about the content of the PDF they're viewing and receive concise, relevant answers without leaving the page.

## 🚀 Features

- **Contextual Q&A**: Pose questions related to the open PDF and get immediate answers.
- **Seamless Integration**: Works directly within Chrome's PDF viewer, eliminating the need for external applications.
- **User-Friendly Interface**: Intuitive design ensures ease of use for all users.
- **Privacy-Focused**: Processes data locally or with secure APIs to ensure user data remains confidential.

## 🛠️ Skills & Technologies Used

- **Languages**: JavaScript, HTML, CSS
- **Frameworks & Libraries**:
  - Chrome Extensions API
  - PDF.js for rendering and interacting with PDF content
  - OpenAI API for natural language processing
- **Tools**:
  - Webpack for module bundling
  - ESLint for code linting
  - Jest for testing

## 🔧 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mariaxu1019/q-aTool.git
2. Open Chrome and navigate to chrome://extensions/.

3. Enable "Developer mode".

4. Click on "Load unpacked" and select the cloned q-aTool directory.

5. The extension should now appear in your Chrome toolbar.
