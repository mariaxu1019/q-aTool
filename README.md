# 📄 q-aTool: AI Assistant for PDFs in Chrome

This tool allows users to ask questions about the content of the PDF they're viewing and receive concise, relevant answers without leaving the page.


## 🛠️ Skills & Technologies Used

- **Languages**: Python, JavaScript, HTML, CSS
- **Frameworks & Libraries**:
  - LangChain
  - QDrant
  - FastAPI
